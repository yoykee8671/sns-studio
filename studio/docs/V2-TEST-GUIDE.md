# v2 로컬 테스트 가이드

v2 브랜치에서 `npm run dev` (http://localhost:3100) 로 확인하는 순서입니다.
전부 로컬 파일 모드(`content/` 폴더) 기준이고, 운영 Supabase는 건드리지 않습니다.

> ⚠️ `studio/.env.local`에 SUPABASE_URL이 있으면 dev도 운영 버킷을 봅니다.
> v2 테스트 동안은 `.env.local`에서 `SUPABASE_URL` 줄을 잠시 주석 처리하세요
> (`# SUPABASE_URL=...`). 테스트 후 되돌리면 됩니다.

```bash
cd studio && git checkout v2 && npm run dev
```

## 1. 기존 게시물 회귀 확인
- 홈에서 기존 게시물(예: 2026-10-*)을 열어 v1과 똑같이 보이는지 확인.

## 2. 장별 템플릿 + 새 속지 3종
- 샘플 게시물 **2026-11-zz-v2-smoke**를 열면 넘버링/리스트·정보 표/아이템 소개
  3장이 보입니다 (textStyle 데모 포함).
- 오른쪽 패널 "이 장의 템플릿" 드롭다운으로 장마다 템플릿을 바꿔보세요.
- "+ 장 추가"는 직전 장과 같은 템플릿으로 추가됩니다.

## 3. 인라인 마크업
- 아무 텍스트 칸에 `**굵게**`, `==형광펜==`, `{{blue|파란 글씨}}` 입력 → 미리보기 반영.
- 리스트 템플릿 항목 칸은 `라벨 | 설명` 한 줄 = 한 행.

## 4. 글자 세부 조정
- 장 편집 탭의 "글자 세부 조정" 접이식 패널 → 필드별 크기/자간/행간 슬라이더, 초기화.

## 5. 연재 관리
- 홈 상단 "연재 관리" 펼침 → 새 연재 만들기 → 기존 게시물 선택해 "연재에 넣기"
  → "00N호 만들기" 누르면 지난 호 구성 복사된 새 게시물이 열립니다.
- 홈 목록에 ○○호 뱃지 확인.

## 6. AI 캡션 초안
- 캡션 탭 → "✨ 캡션 초안" → 자세히/짧게 전환, "캡션에 넣기"/"해시태그 넣기".
- (로컬 .env.local의 ANTHROPIC_API_KEY 필요 — 이미 설정돼 있음)

## 7. 발행됨 표시 + 미디어 정리
- 상단 제목 옆 상태 뱃지가 셀렉트로 바뀜 → "발행됨" 선택 → 모달에서
  "표시 + 미디어 정리" / "표시만 하기" 선택.
- 정리 후에도 게시물이 열리고(빈 사진 칸), 홈 상단 "서버 미디어 용량" 숫자가 줄어듦.
- ⚠️ 정리는 되돌릴 수 없으니 테스트는 버려도 되는 게시물로.
