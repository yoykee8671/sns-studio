# SNS Studio v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Edito-inspired v2 — per-slide templates, 3 new inner templates, series management, field text styles, inline emphasis markup, AI caption drafts, media purge — all tested locally, deployed only when v2 is declared done.

**Architecture:** Keep the template-module contract (`renderSlide()` returns a full HTML doc, shared by preview iframe and Playwright export). Add `slide.template` with `post.template` fallback; new capabilities enter as small lib modules (`markup.mjs`, `series.mjs`) + thin API routes + editor panel sections.

**Tech Stack:** Next.js 16 App Router, React 19, node:test for lib tests, Supabase Storage (prod) / local file mode (dev), @anthropic-ai/sdk + zod for AI.

**Spec:** `studio/docs/superpowers/specs/2026-11-06-studio-v2-design.md`

## Global Constraints

- Dev/test on local file mode only (SUPABASE_URL unset → `content/` folder). Never point dev at the production bucket.
- Branch: long-lived `v2` off main; each task lands as `feat/v2-<name>` PR with base `v2`, squash-merged. Never commit to main.
- Backward compat: a post.json without the new fields must render pixel-identical (fallbacks everywhere).
- One line in a textarea = one line in the design; `data-max-lines` + overflow QA must keep working for all new fields.
- UI copy in Korean, code comments/commits in English, single quotes, max line 100, kebab-case files.
- New templates: `role: 'inner'`, `formats: ['carousel', 'single']` (no reel), white background, 110px side margins, fonts/colors only from brand kit.
- Tests: `node --test tests/` (new dir) for lib logic; `node --check` every touched .mjs; visual check via `npm run dev` (user does final pass).

## Review Focus

1. Legacy post.json (no slide.template/textStyle/markup) → renders identical to v1; pinned by resolveTemplate fallback test (Task 2) + markup passthrough test (Task 1).
2. Literal `**`, `==`, `|`, `{{` typed by the user in existing fields must not corrupt output → markup parser tests cover unmatched/ unclosed markers passing through verbatim (Task 1).
3. Reel posts: slide.template naming a no-reel template must fall back to post.template → resolveTemplate guard test (Task 2).
4. Export of a mediaPurged post → media-missing placeholder, no crash → purge route test keeps post loadable (Task 7).
5. "다음 호 만들기" when the latest issue's post was deleted → falls back to newest existing issue, else blank template → series test (Task 5).
